# Le fotografie della home, originali

Quattro immagini **illustrative generate**, non fotografie documentali di indirizzi verificati:
non rappresentano immobili in vendita e la home lo dichiara nel piede della pagina.

| File | Cosa mostra |
|---|---|
| `02-cortile-milanese.png` | l'ingresso aperto su un cortile con le piante — è la prima della rotazione e l'unica che si vede su telefono |
| `01-balconi-liberty.png` | balconi in ferro battuto, persiane verdi, pietra scolpita |
| `03-ingresso-ferro-vetro.png` | portone ad arco in ferro e vetro |
| `04-ingresso-pietra-bronzo.png` | ingresso sobrio in pietra, bronzo e vetro |

Sono i file originali: 1536×1024 PNG, circa 2,5–3 MB ciascuno. **Non vengono serviti**: questa
cartella sta fuori da `public/`. Le copie per il sito stanno in `public/hero/`, in WebP e AVIF a
768, 1152 e 1536 px di larghezza (mai ingrandite oltre l'originale), generate con
`scripts/ottimizza-hero.py (Pillow: `pip install pillow pillow-avif-plugin`)`.

`brief-originale.txt` è la richiesta con cui sono state integrate, tenuta per memoria.

Le fotografie precedenti della home stanno in `archivio/`.
