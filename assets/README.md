# assets/ — i sorgenti, non i file serviti

Qui stanno gli originali pesanti da cui nascono i file del sito. **Non è dentro `public/`**:
niente di qui viene servito. In `public/` vanno solo le copie ottimizzate.

| Cartella | Cosa contiene |
|---|---|
| `hero/` | le quattro fotografie della home, PNG originali, più il brief con cui sono state scelte |
| `hero/archivio/` | le fotografie della home precedenti, tenute per memoria |
| `marchio/` | la tavola di presentazione del marchio; i file veri stanno in `public/logo/` |
